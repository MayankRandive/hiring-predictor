# AI Resume Screening System
This is an **AI-powered resume screening system** built with **XGBoost** and **Streamlit**. It predicts whether a candidate is likely to be **Hired** or **Not Hired** based on resume features like skills, experience, education, and more.

The app also shows **top 10 feature importances**, giving insights into what factors influence the prediction most.
---
**Features**

- Predict candidate hiring outcome (`Hired` / `Not Hired`)
- Displays **prediction probability**
- Interactive **Streamlit UI** for inputting candidate details
- Top 10 **feature importance graph**
- Fully deployable on **Streamlit Community Cloud**
